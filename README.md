# Сборка прошивки Octopus PnP в GitHub Actions
Configuration.h и Configuration_adv.h — конфигурация Marlin для BTT Octopus V1.1 (OpenPnP + фидеры Photon).
Сборка запускается автоматически при каждом изменении файлов. Готовый firmware.bin — во вкладке Actions,
в последнем запуске, раздел Artifacts → firmware-octopus-pnp.
